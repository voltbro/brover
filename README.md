# BRover ROS 2 packages

Репозиторий `brover` содержит основные ROS 2 пакеты управления ровером BRover. Пакеты рассчитаны на ROS 2 Jazzy и работают вместе с `cyphal_ros2_bridge`, который связывает ROS-топики и сервисы с бортовой CAN/Cyphal сетью.

На ровере пакет обычно запускается автоматически через systemd-сервис `ros_nodes.service`.

## Состав

```text
brover_control/             общий launch-файл и конфигурация
brover_move_control/        преобразование /cmd_vel в команды шести колес
brover_radiolink_control/   управление от Radiolink-джойстика
brover_odom_simple/         простая 2D-одометрия по энкодерам и IMU yaw
brover_bat_monitor/         мониторинг батареи и управление HMI LED
brover_imu_node/            публикация BHI360 IMU из USB HID интерфейса
test_move.py                ручной сценарий движения для проверки управления
test_encoders.py            терминальный монитор значений /m_odom1 ... /m_odom6
```

## Запуск

Основной launch-файл находится в `brover_control/launch/brover_control_launch.xml`. Он запускает:

- `cyphal_ros2_bridge/cyphal_bridge`;
- `brover_move_control/move_node` с именем ноды `control_move`;
- `brover_radiolink_control/direct_joystick_node` с именем ноды `joy`;
- `brover_radiolink_control/radiolink_node` с именем ноды `radiolink_control`;
- `brover_imu_node/imu_node` с именем ноды `imu`;
- `brover_odom_simple/odom_pose2d` с именем ноды `odom`;
- `brover_bat_monitor/bat_monitor_node` с именем ноды `bat_monitor`.

## Переход на ветку

Ветка `kosmo-arm` включает управление манипулятором в штатный запуск BRover. Для перехода с `main` на настроенном ровере с ROS 2 Jazzy выполните следующие шаги.

1. Подключитесь к Raspberry Pi по SSH. Поставьте CH5 в среднее положение, отцентрируйте стики и остановите управление.

   ```bash
   sudo systemctl stop ros_nodes.service
   cd ~/ros2_ws/src/brover
   git status --short --branch
   ```

2. Сохраните локальные правки, если они есть. Получите ветку из удалённого репозитория и создайте на ровере локальную ветку `kosmo-arm`, отслеживающую `origin/kosmo-arm`.

   ```bash
   git fetch origin
   git switch --track origin/kosmo-arm
   ```

3. Для ServoBoard используйте [скетч KosmoArmCan](firmware/KosmoArmCan/KosmoArmCan.ino) из этой ветки. При первой установке загрузите его по SWD в VB32G4. ServoBoard подключается к CAN1, который на проверенном ровере соответствует Linux-интерфейсу `can1`.

4. Соберите пакеты в штатном рабочем пространстве. После успешной сборки запустите службу:

   ```bash
   cd ~/ros2_ws
   source /opt/ros/jazzy/setup.bash
   colcon build --packages-select brover_radiolink_control brover_control
   ```

   ```bash
   sudo systemctl start ros_nodes.service
   systemctl is-active ros_nodes.service
   ```

   Ожидаемый ответ — `active`. Служба использует обычный launch-файл ветки. Дополнительные аргументы для включения манипулятора не нужны.

## Управление ровером

На Radiolink T8S переключатель **CH5 (SWB)** выбирает, чем управляют стики. После запуска или переподключения пульта сначала установите CH5 в середину и отцентрируйте стики.

| CH5 | Действие |
| --- | --- |
| Вниз | Езда. Правый стик вверх/вниз задаёт ход, левый влево/вправо — поворот. CH7 вниз — высокая скорость, середина — обычная, вверх — низкая. Манипулятор удерживает позу. |
| Середина | Пульт прекращает движение ровера, манипулятор удерживает позу. Команды езды из веб-интерфейса по-прежнему доступны. |
| Вверх | Управление манипулятором. CH7 выбирает назначение правого стика. |

**Первое включение манипулятора.** Выберите крайнее положение CH7, отпустите CH6 и переведите CH5 вверх при нейтральных стиках. При первом разрешении после включения ServoBoard все шесть приводов получают стартовую уставку 90°. Нажимать CH6 для начала работы не требуется.

| CH7 (SWA) | Левый стик ↔ | Левый стик ↕ | Правый стик ↔ | Правый стик ↕ |
| --- | --- | --- | --- | --- |
| Вниз | Поворот базы | Первый сустав | Третий сустав | Второй сустав |
| Середина | Удержание | Удержание | Удержание | Удержание |
| Вверх | Поворот базы | Первый сустав | Вращение схвата | Открытие и закрытие схвата |

Чем дальше отклонён стик, тем быстрее движется соответствующий привод. Верните ось в центр, чтобы остановить его в достигнутом положении. Если вертикаль левого стика без пружины, верните её вручную. При переключении CH7 новое назначение правого стика действует сразу: если стик отклонён, начнёт двигаться выбранный привод.

**Возврат к 90°.** При верхнем CH5 и крайнем положении CH7 отцентрируйте стики и удерживайте CH6. Приводы будут двигаться к стартовой позе, пока кнопка нажата. Отпустите её, чтобы остановить возврат.
