# BRover-E5 и KOSMO-Arm с Radiolink T8S

| CH5 (SWB) | Колёса | Манипулятор |
| --- | --- | --- |
| Верх | Пульт не задаёт движение | CH7 переключает правый стик. Стики управляют без CH6 |
| Середина | Пульт не задаёт движение | Удерживает последнюю заданную позу |
| Низ | Доступны. CH7 выбирает скорость как раньше | Удерживает последнюю заданную позу |

Отклонение каждой из четырёх осей задаёт скорость. Нулевое положение останавливает соответствующий привод. Вертикаль левого стика без пружины нужно возвращать в центр вручную.

| CH7 | Левый ↔ / ↕ | Правый ↔ / ↕ |
| --- | --- | --- |
| Вниз | База / первый сустав | Третий / второй сустав |
| Вверх | База / первый сустав | Вращение / открытие или закрытие схвата |

Среднее положение CH7 удерживает все оси. Для Mode 2 ожидаются индексы левого стика 3/2 и правого 0/1. Дополнительные оси задаются параметрами `arm_left_vertical_axis` и `arm_right_horizontal_axis`. Проверьте соответствие по `/joy`.

После запуска или пропадания `/joy` сначала установите CH5 в середину. Для езды переведите CH5 вниз и отцентрируйте обе оси. Для манипулятора переведите CH5 вверх, установите CH7 в крайнее положение, отцентрируйте стики и отпустите CH6. При первом входе в режим манипулятора плата автоматически задаёт всем приводам 90°. Затем управляйте стиками. При удержании CH6 в нейтрали суставы возвращаются к стартовой позе. При переключении CH7 текущее отклонение правого стика сразу применяется к выбранным приводам.

## Настройка и проверка

1. Проверьте на Raspberry Pi соответствие физического CAN1 интерфейсу Linux и номинальную скорость CAN. Используйте `ip -details -statistics link show type can`, `candump can1` и действующую конфигурацию платы CAN HAT. Скетч использует 1 Мбит/с для арбитража. Для фазы данных CAN FD используются штатные настройки библиотеки VBCoreG4_arduino_system (8 Мбит/с на этом ровере). Убедитесь, что стандартный ID `520` свободен.
2. Соберите скетч в Arduino IDE для STM32duino → Generic STM32G4 → Generic G474RETx с библиотекой VBCoreG4_arduino_system и штатной библиотекой Servo. Загрузите скетч по SWD. После включения платы кадры удержания оставляют выходы сервоприводов выключенными.
3. Пересоберите ROS-пакеты и запустите экземпляр основного launch с теми же параметрами Cyphal и окружением ROS, которые использует ровер. Перед ручным запуском остановите штатный экземпляр запуска, чтобы не дублировать управление приводами.

   ```bash
   cd ~/ros2_ws
   source /opt/ros/jazzy/setup.bash
   colcon build --packages-select brover_radiolink_control brover_control
   source install/setup.bash
   ros2 launch brover_control brover_control_launch.xml
   ```

4. Проверьте `ros2 topic echo /joy`. Код ожидает CH5 на `axes[4]` со значениями −1 внизу и +1 вверху, CH7 на `axes[6]`, CH6 на `axes[5]` с −1 при отпущенной кнопке и +1 при нажатой. Если CH6 инвертирован, задайте `arm_enable_direction: -1.0` для узла `radiolink_control` в используемом YAML. Если адаптер выдаёт кнопку через `buttons[]`, задайте её индекс в `arm_enable_button`. Проверяйте потерю радио отдельно от отсоединения USB. Если адаптер продолжает публиковать последние значения после выключения передатчика, настройте failsafe приёмника, чтобы CH5 возвращался в середину и CH6 в состояние отпускания. До проверки этого поведения держите приводные колёса и манипулятор в безопасном испытательном положении.
5. До первого входа в режим манипулятора проверьте кадры через `candump can1,520:E00007FF`. При CH5 внизу пульт управляет колёсами, а манипулятор получает команду удержания. При выходе из режима езды пульт передаёт нулевую скорость. Веб-интерфейс может управлять колёсами при любом положении CH5.
6. Проверьте на собранном манипуляторе, что общие пределы `MIN_ANGLE` и `MAX_ANGLE` подходят всем суставам, а поза соответствует `HOME_ANGLE`. Скорость задаёт `SPEED_DEG_PER_SEC`. При первом разрешении управления все приводы получают стартовую уставку автоматически.
7. Проверьте удержание после центрирования стиков, смены положения CH5 и прекращения CAN-команд. Таймаут на плате составляет 150 мс, при этом PWM сохраняет последние уставки при наличии питания. После восстановления связи верните CH5 в середину и отцентрируйте стики. При сбросе платы последняя поза теряется.

## Команда CAN

Стандартный кадр Classical CAN `0x520`, DLC 8. Байт 0 — `A2`, байт 1 — `00` для удержания либо `01` для движения, либо `02` для установки стартовой позы (все скорости нулевые). Байты 2–7 — шесть знаковых скоростей от −100 до 100 в порядке пинов в `SERVO_PINS`. Пакет удержания — `520#A200000000000000`. В штатном запуске отправка идёт каждые 50 мс. Плата начинает принимать ненулевые скорости после кадра удержания и разрешающего кадра с нулевыми скоростями.

В ветке `kosmo-arm` штатный launch включает управление манипулятором по умолчанию.
